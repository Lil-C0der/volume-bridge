# VolumeBridge app icon

Selected concept D: connected storage volumes in cyan and sapphire glass on a silver rounded tile.
`VolumeBridge.png` is the transparent raster master. `build.py` generates standard and Retina ICNS representations using macOS `sips` and `iconutil`.

Generated with the built-in image_gen tool. Original concept prompt:

> Create a premium macOS Liquid Glass app icon for VolumeBridge, an NTFS external disk read/write utility. Pearl and cool silver rounded square base. Two thick rounded rectangular glass disk platters stacked with slight vertical separation, top ice cyan, bottom sapphire blue, linked by a single short central translucent bridge. Subtle tiny indicator dot on lower front edge. Compact bold storage silhouette, restrained layered translucent materials, subtle refraction and crisp specular edges. No text.

Production edit prompt:

> Preserve the silver tile, disks, connector and indicator. Remove the pale studio background and broad cast shadow, replace with transparent alpha. Refine the outer edge by removing stray pixels and fringes; retain the inner design and glass rendering.

This artwork is a static raster icon; dynamic Liquid Glass appearances require layered Icon Composer assets.
