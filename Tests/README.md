# 挂载流程回归测试

在交付目录运行：

```sh
python3 Tests/test_regressions.py
```

依赖 Python 3 和本机 Swift 编译器。20 个用例覆盖 NFS → 原生只读、已卸载卷的空/缺失 MountPoint、原生只读 → 读写、读写重试、并发卸载、只读挂载结果验证、占用、权限拒绝、驱动错误、异步挂载失败、UUID 变化、内部磁盘保护与错误提示。

测试每次从当前 `Source/VolumeBridge.swift` 提取 `helper` 的原始函数体，并替换底层依赖为可观察的模拟函数。每个用例运行在独立进程中，断言磁盘操作顺序和最终状态。生产源码的设备打开、Process 执行、diskutil 查询和 NFS 挂载函数均由模拟实现接管。临时文件仅保存在随机生成的测试目录，运行结束自动清理。

失败用例会报告具体操作序列。当前实现的缺陷会直接导致测试失败；修复主程序后重新运行可作为回归门槛。应用里的「验证读写」另行覆盖 NTFS 测试镜像的实际文件读写。
